# Maintenance Process

## Monthly Routine

1. Open the website on desktop and mobile.
2. Submit the contact form with a test message.
3. Check main CTA links.
4. Check footer links.
5. Review analytics if available.
6. Apply included client edits.
7. Send short monthly summary.

## Edit Rules

Included:
- Text changes.
- Replacing images.
- Updating hours.
- Adding a small section.
- Updating CTA links.

Not included:
- Full redesign.
- New website pages beyond plan.
- New app features.
- Emergency support unless sold separately.
- SEO guarantee.
