Cookie Policy

GrowthStack does not currently set advertising, analytics, profiling, or preference cookies. No non-essential cookie is intentionally placed by the site's own code.

Current setup

The site is static and uses local images, styles, scripts, and fonts. It does not load advertising pixels, Google Analytics, external web fonts, embedded social feeds, maps, videos, live chat, or payment widgets. Contact forms on GitHub Pages prepare an email draft instead of storing a submission in a website database.

Hosting logs

GitHub Pages and network providers may process IP addresses, request times, user-agent data, and security logs needed to deliver and protect the service. These provider operations are not used by GrowthStack for advertising or visitor profiling.

Why there is no cookie banner

The current site does not intentionally place non-essential cookies, so it does not show a consent banner. This position must be tested again whenever hosting, analytics, media, booking, chat, payment, or marketing tools change.

If tools are added later

If analytics, embedded media, remarketing, booking, live chat, or payment tools are added, GrowthStack will document the provider, purpose, data, duration, and recipients. Where consent is required, those tools must remain blocked until a visitor actively accepts them, and refusing must be as clear as accepting.
